# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

## [1.0] - 2024-01-15

### Agregado
- ✨ Obtener IP Pública (usando ipify API)
- ✨ Mostrar IPs Locales
- ✨ Información detallada de IPs (país, ciudad, ISP, coordenadas)
- ✨ Geolocalización de direcciones IP
- ✨ Función Ping a hosts
- ✨ Consultas DNS (nslookup/dig)
- ✨ Verificación de puertos comunes
- ✨ Interfaz colorida con banners ASCII
- ✨ Menú interactivo fácil de usar
- 🚀 Script de instalación automática
- 📖 Documentación completa en README
- 📋 Soporte para Termux y Linux

### Características principales
- Banner ASCII con colores
- 8 opciones principales de funcionalidad
- Interfaz amigable en español
- Uso de APIs confiables
- Sin dependencias complicadas

### Requisitos
- bash
- curl o wget
- ping
- nslookup o dig (opcional)

### Notas
- Versión inicial
- Completamente funcional
- Probado en Termux y Linux

## Convenciones de versioning

Este proyecto sigue [Semantic Versioning](https://semver.org/lang/es/).

- **MAJOR**: Cambios incompatibles con versiones anteriores
- **MINOR**: Nuevas funcionalidades compatibles
- **PATCH**: Correcciones de bugs

Formato: `MAJOR.MINOR.PATCH`
